Is this safe to use while MapleStory is running?

This page never touches the game. It does not read game memory, does not watch your screen or keyboard, and does not send input to the game. It only sees the images you give it, the same as uploading a picture anywhere else.

Take screenshots with tools that do not hook into the game: the game's own screenshot key (Print Screen), or Windows Snipping Tool (Win+Shift+S, then paste here). If a capture comes out black, switch the game to windowed or borderless mode. Avoid third-party overlay or recording tools that inject into the game client.

Nothing here automates gameplay, so it is no different from a spreadsheet you fill in yourself.

Socket bases

Prismatic jewels only boost a Hologram skill that is already 3/3 on gear, from Lv. 3 to Lv. 8. A build needs one Prismatic per maxed skill; every other socket should be a colored stat jewel for your class. Sync with GitHub

Keeps your line fodder, socket bases and settings in a JSON file in your repository, so every machine you use sees the same data.

This claude.ai page can't connect to GitHub. Open the app from your repository instead (index.html, or GitHub Pages) to sync, or move data here with Export and Import below.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens/new (a fine-grained token).
  2. Under Repository access, choose Only select repositories and pick this repository.
  3. Under Permissions → Repository permissions, set Contents to Read and write. Nothing else is needed.
  4. Generate it, copy it, and paste it in the token field above. Do this once on every machine.

The token is kept only in this browser on this machine. It is never put in exports or in the synced file.

Both this machine and GitHub have changes. Choose which version to keep. The other one is replaced.

Export

Your inventory saves automatically in this browser. Export it to keep a backup or move it to another device.

Paste a JSON export or CSV, or pick a file. CSV columns: slot, line1, line2, line3, socket1, socket2, socket3, note, type (type is fodder or base). Skill names or codes both work.
